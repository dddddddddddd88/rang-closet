TRENDORA 쇼핑몰 프론트엔드 데모

실행 방법
1. 압축을 풉니다.
2. index.html 파일을 Chrome, Edge, Safari 등에서 엽니다.
3. img 폴더는 index.html과 같은 위치에 유지합니다.

포함 기능
- 4장 히어로 자동 슬라이드 및 좌우 이동
- 카테고리, 신상품/베스트 상품, 장바구니 데모
- 로그인/회원가입/등급 안내 모달
- 테스트 주문/결제 화면
- 반응형 레이아웃

중요
현재는 정적 프론트엔드 데모입니다. 실제 회원가입/로그인, 개인정보 저장, 포인트 적립/차감, 주문 저장 및 카드 결제 승인에는 백엔드 API, 데이터베이스, PG사(예: 토스페이먼츠/이니시스) 연동과 보안 검수가 필요합니다. 상품 사진은 생성된 패션 시안 이미지에서 크롭한 로컬 이미지입니다.
